# Gene Expression Analysis Using R

## Project Overview
This beginner bioinformatics project demonstrates how R can be used to analyze and visualize gene expression data. The workflow includes basic data handling, descriptive statistics, filtering genes by expression level, and creating a bar plot using ggplot2.

## Objectives
- Calculate the mean, maximum, and minimum expression values.
- Identify genes with expression values greater than 50.
- Visualize gene expression using a bar plot.
- Export the dataset and graph for further use.

## Tools Used
- R
- RStudio
- ggplot2

## Files
- `day6_gene_expression.R` — R analysis script.
- `day6_gene_expression.csv` — gene expression dataset.
- `day6_gene_expression.png` — generated bar plot.

## Dataset
The dataset contains simulated expression values for six genes: BRCA1, TP53, EGFR, MYC, KRAS, and APC. These values are illustrative and do not represent real experimental measurements.

## Skills Practiced
Data manipulation, descriptive statistics, filtering, data visualization, and exporting results.

## Limitations
This is a learning project using simulated data. The results should not be interpreted as biological or clinical findings.

## Future Improvements
The next step is to apply similar analytical skills to real public gene expression datasets.
